# 二维与三维单步控制

日期：2026-10-30。

## 操作与状态

暂停时点击「单步」推进一个固定物理时间步，完成后仍保持暂停。步长使用当前 `Engine.PhysicsTicksPerSecond` 的倒数：项目默认 60 Hz 时为 1/60 秒，120 Hz 时为 1/120 秒。运行时按钮禁用，调用世界的 `StepOnce()` 也不推进。

一次单步执行原有的邻居搜索、群集、边界、运动和障碍接触计算，并更新调试图形与最近一次统计。个体实例、ID、随机种子、选择、领队和障碍布局保持不变；相机继续按显示帧更新，之后的物理帧不会因为单步而继续推进。

二维领队沿用当前鼠标目标。三维操作按钮前先按 Esc 释放鼠标；释放会清除移动输入，因此单步中的领队按原加速度限制制动。单步没有新增快捷键，按钮有焦点时 Enter 可按原生控件行为激活；空格始终只切换暂停/继续，输入框的 Enter 不会触发单步。帮助和世界切换期间屏蔽后台请求。

数量另由输入提交触发即时增减，种子仍在重置后生效；单步不会生成新群体。

## 更新路径

两个管理器的 `CanStep` 均为 `!IsRunning`，`StepOnce()` 检查该条件后调用同一个 `Step(1.0 / Engine.PhysicsTicksPerSecond)`。MainController 过滤帮助、待切换与三维捕获状态，随后刷新 HUD。没有新增计时器、待执行步数或第二套积分逻辑。

## 验收

C# 构建零警告、零错误，完整 24 组无图形回归通过。新增 `tests/single_step_checks.tscn` 共 137 项检查：

- 真实主场景中的二维/三维按钮操作，在 60/120 Hz、朴素/网格模式下，与直接推进一次的全部运动状态一致；另用 60 单位/秒匀速个体独立验证 120 Hz 下位移为 0.5 单位。
- 单步后跨物理帧与显示帧保持暂停，无额外位移；调试箭头、统计和按钮状态刷新。
- 运行时直接调用、禁用按钮和排队请求均不执行；空格长按、按钮焦点、数字输入、帮助弹窗、切换中的旧世界请求不会额外推进。
- 反复 2D/3D 切换后一次点击仍只推进一次；保留实例与种子，空群体统计为零，重置清除旧测量。
- 两种领队保留身份、选择和障碍；三维释放后的单步制动、相机继续更新且个体保持暂停。

测试使用独立配置文件。可通过现有运行器的 `-Scenes single_step_checks` 单独执行；检查通过真实视口发送输入，但使用无窗口模式，不属于真实键盘或图形手感验收。
