# 实机验收清单

更新日期：2026-10-31。代码开发和自动回归已完成。按维护者安排，以下项目由维护者在实际窗口中检查；所有项目目前均为待验收，不代表发现了代码缺陷。

## 准备

使用 Godot 4.7.2 .NET 启动 `scenes/main_3d.tscn`，或从主场景顶部切换三维。构建方式见[项目 README](../README.md)。记录测试提交、窗口尺寸和关键参数，后续定位问题时沿用同一组设置。

观察和操控测试使用正常的非零最大速度、最大加速度与角运动上限。需要 40 / 200 个跟随者时，将请求总数设为 **41 / 201**，再指定其中一个为领队。界面指定领队会立即捕获鼠标；按 Esc 释放后再操作参数。

## 三维观察与显示

- [ ] 勾选 / 取消「显示边界」和「显示网格」，确认各自独立控制显示；边界关闭时仍有软边界回归。
- [ ] 暂停时缩小观察盒，个体与障碍保持位置；继续运行后，范围外个体逐渐返回，无跨边传送。旋转、平移、缩放相机不改变模拟范围，Home 按最新范围取景。
- [ ] 检查普通、选中、领队、选中领队的外观，取消普通选择后领队身份仍清楚；分离半径超过感知半径时出现黄色提醒，恢复后隐藏。

## 领队与真实键盘

- [ ] 指定或转移领队后自动进入操控，保留原暂停 / 运行状态；Esc 释放，F3 或按钮恢复操控。失焦或关闭帮助后不自动重新捕获。
- [ ] W/S、A/D 以相机目标视角为参考，俯仰可以改变前后飞行的高度，组合输入不额外加速。领队朝向跟随实际运动方向，静止时转动相机不会让领队主动对齐镜头。
- [ ] 松键或退出操控后平滑刹停；领队碰到障碍时阻挡并沿表面滑动，不主动绕障。关闭主动避障后仍保留领队接触约束。
- [ ] 空格暂停时保持捕获，鼠标仍能调视角，个体不自动移动或转向；释放状态下右键拖动也能调整暂停中的跟随视角。
- [ ] 检查 F1、F2、Esc、F3、文本输入焦点、窗口失焦、重置和 2D/3D 切换；编辑数字时 WASD 不操控，空格仍只切换暂停 / 继续。

## 相机、队形与障碍编辑

- [ ] 分别使用 40 / 200 个跟随者，在静止、连续转弯、侧移、后退时观察队形和相机平滑；比较 300 与 650 视距，记录持续遮挡的位置与大致时长。
- [ ] 开关「淡化近处个体」，确认近镜头普通个体淡化、身份高亮保留，切回观察模式后恢复普通外观。选中个体仍不透明，可能继续遮挡领队。
- [ ] 在跟随视角释放鼠标，选择前后不同深度的个体与障碍；放置或拖动期间画面与编辑平面稳定，结束后恢复平滑跟随。相机自身没有障碍碰撞。

## 共享控制与状态衔接

- [ ] 二维和三维分别切换「基础 → 朝向转动 → 限制角速度与角加速度」，确认关闭后外观直接跟随速度、接触滑动后无转向延迟；停稳和极低速度不抖动。再开启恢复原有上限，暂停切换不推进位置，三维位置和相机仍平滑。
- [ ] 二维「显示 → 二维观察边界」启用软边界，确认四边及角落逐渐转向，平移/缩放后不搬移个体，暂停保持位置。指定领队后无限运动，取消身份恢复软边界；关闭开关恢复原有环绕。
- [ ] 二维、三维暂停时各点击单步，确认只推进一下并更新图形 / 统计；随后持续保持暂停。运行时按钮禁用，按钮有焦点时空格不额外推进。
- [ ] 数量输入未提交时群体不变；Enter 或失焦后增减，保留剩余个体运动和运行状态。分别检查普通观察、领队模式、缩到一只和零只；障碍布局保持。
- [ ] 在受障碍限制的生成范围中增加数量，确认请求数与实际数显示清楚；清出空间后再次 Enter 可以补充。未完成新增不会在后台无限重试。
- [ ] 反复切换二维 / 三维，确认各自参数保存，目标世界重新生成并暂停；二维原有环绕、鼠标领队和障碍操作保持正常。

## 统一避障与不规则障碍（本轮未执行图形验收）

- [ ] 二维鼠标领队穿过多个障碍间的缝隙，分别测试正面、斜向接近和从通道内静止起步。把鼠标停在缝隙中、在目标后方添加障碍，确认不会因此明显绕远；真正小于个体安全直径的缝隙仍应阻挡。
- [ ] 按[接入说明](obstacle-query-refactor.md)加载二维 L 形与三维组合凸体，确认凹口可见、通道开放，碰撞轮廓与预期一致。
- [ ] 明暗主题下选中个体并开启「显示运动方向」，确认前向探测、候选状态、最终方向和接触法线可读；隐藏时无残留。
- [ ] 暂停创建、移动和改尺寸后单步，确认只推进一个固定步；观察深重叠恢复和角落滑动，没有额外跳动。
- [ ] 40/200 跟随者绕过障碍并转弯，记录短暂拥挤及恢复过程；连续领队飞行时确认显示插值与相机观感未退化。
- [ ] 检查自定义障碍整体选择、拖动、删除，以及带父节点旋转的编辑手感。自定义尺寸通过资源编辑，不使用原四种形状的尺寸控件。
