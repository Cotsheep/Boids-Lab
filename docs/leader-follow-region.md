# 领队跟随范围显示

在「领队 → 跟随队形」勾选「显示跟随范围」，可查看跟随者实际追踪的区域。默认关闭，二维、三维分别保存选择；显示不依赖当前是否选中领队。

二维使用领队主题色的淡透明圆面、细亮轮廓、柔和外晕和中心点，绘制在个体下方。三维显示淡透明球面与三条圆周轮廓，保留场景深度遮挡、不投影或写入深度；镜头进入球体时填充淡出，减少整屏染色。明暗主题沿用各自的领队颜色。

圆心 / 球心在领队后方，半径直接使用跟随算法计算的结果：二维按跟随人数平方根扩大，三维按立方根扩大。「领队后方距离」控制领队到区域前缘的间隔。修改距离、分离半径或数量后，显示立即更新。

二维沿用实际跟随算法保留的方向，不随滞后的外观转头而偏移；三维随领队的显示插值姿态移动和转动，避免运行时范围抖动。暂停时切换开关、修改参数或更换领队只刷新显示。

未指定领队、跟随权重为零，或跟随者少于两名时不显示面积 / 体积；一名跟随者的算法目标半径为零，不人为放大成可见圆。删除、取消身份、重置或切换世界会清除旧范围。

该功能只用于观察，不增加碰撞、改变群集运动、相机和拾取。代码位于 `SimulationView`、`SimulationView3D`，开关为 `BoidConfig.ShowLeaderFollowRegion`，保存键为 `visualization/show_leader_follow_region`。

`tests/leader_follow_region_checks.tscn` 覆盖开关与旧配置兼容、二维/三维独立保存、真实区域位置、暂停修改、生命周期、三维插值和显示开关前后逐步轨迹一致性。明暗主题的同状态开关图可通过 `tests/diagnostics/leader_follow_region_visual.tscn` 使用 Compatibility 图形渲染器生成，输出在 `.godot/validation/leader-follow-region/`。
