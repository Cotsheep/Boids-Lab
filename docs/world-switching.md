# 运行时世界切换

从任一主场景启动后，可使用顶部选择器切换二维与三维世界。切换后目标世界重新生成并暂停，不保留个体运动状态、选择、领队、障碍物布局或相机视角。HUD 显隐保持不变，帮助弹窗关闭并换成目标世界的说明。

## 入口与数据

- `SimulationWorldDefinition` 是普通 Godot Resource，包含场景、名称、配置文件路径和操作说明。
- `world_2d.tres` / `world_3d.tres` 分别指向两个世界，使用 `user://boids_lab.cfg` / `user://boids_lab_3d.cfg` 保存参数。
- `main.tscn` 默认进入 2D，`main_3d.tscn` 仅将 `StartIn3D` 设为 true；两者都可以运行时切换。
- `MainController` 为两种模式各缓存一份 BoidConfig，首次访问时加载。保存失败会显示提示，但当前会话内的设置仍保留；不缓存世界节点或 Boid 状态。

## 切换顺序

1. 顶部选择事件请求切换，暂时禁用选择器，通过 Godot 的延迟调用等待本次输入派发结束。
2. 实例化并初始化目标世界，验证场景根节点实现 ISimulationWorld。
3. 提交旧面板中正在编辑的数字，保存旧配置；未提交的请求数量只保存，不再给即将释放的旧世界新增个体。关闭帮助，暂停、释放领队捕获鼠标并清空按键，取消旧世界输入手势。
4. 解除旧世界与 UI 的事件绑定，将旧世界从场景树移除并释放，结束其相机、环境和窗口事件订阅。
5. 挂入新世界，按目标配置重新生成个体并暂停；重新构建参数控件、绑定事件，重置参数滚动位置与统计读数。
6. 更新场景标题、坐标单位、操作说明和选择器状态。

选择当前模式不重置世界。相机、选择和模拟仍使用 Godot 节点回调；这段流程只负责应用层的世界装卸。

## 验证

`tests/world_switch_checks.tscn` 在无图形模式中验证反复切换、旧世界释放、独立配置保存、未提交数字、暂停与重建、相机替换、帮助和控件恢复、运行状态清理，以及按钮和窗口事件不重复响应。测试使用 `.godot/validation/` 下的独立配置文件。
