# 三维邻居搜索

`NeighborSearch3D.Search(boids, radius, mode)` 在物理步开始时保存真实位置与速度快照，不接收观察盒参数。两种算法共用直接欧氏距离、包含边缘的精确半径判断和快照下标结果；排除自身，包含重合的其他个体。观察和领队模式完全相同。

朴素算法检查 N×(N−1) 个有向配对。均匀网格以感知半径为格宽，按各轴 `floor(position / radius)` 分格，支持负坐标及观察盒外坐标；只保存占用格子，每次检查相邻 27 格，不取模、不周期复制。极端超出整数格索引范围的坐标合并到端部桶，仍按直接距离过滤；浮点坐标本身的精度限制仍存在。

两种搜索均保留按快照下标排序的邻居结果，使群集力累加顺序一致。数组和邻居列表在数量不变时复用，建格、候选过滤和排序均计入搜索耗时。密集场景仍可退化到二次复杂度，不承诺固定加速倍数。

`spatial_3d_checks` 使用独立的双精度欧氏距离参照，覆盖负坐标、百万级坐标、半径边缘、重合、空群体、快照冻结及统计失效，并验证原盒两侧不会成为周期邻居。调试球和连线基于当前真实位置，不截断于观察盒，也不修改物理步统计。`steering_3d_checks` 对照两种搜索驱动的逐步位置、速度和加速度。
