# 三维邻居搜索

`BoidManager3D` 在每个物理步开始时调用 `NeighborSearch3D.Search`，保存全体位置和速度快照。朴素和均匀网格算法共用最短环绕距离、精确半径判断以及结果格式；结果中的整数是快照下标，不是个体 ID。半径边缘和重合的其他个体计为邻居，自身排除。

朴素算法检查全部有向配对，候选次数为 N×(N−1)。网格算法每步重新分配当前个体到格子；每轴格数取 `max(1, floor(边长 / 感知半径))`，再均分完整边长，避免边缘出现残格。多格时格宽至少为感知半径，因此只需检查自身周围最多 27 个格子。越界格坐标环绕；某轴只有一格或两格时只遍历这些格子一次，避免重复候选。

只为空间中已占用的格子创建列表。改变半径会在下次搜索重新计算网格尺寸。查询结果按快照下标排序，与朴素算法使用相同的累加顺序，便于对照后续转向和轨迹；排序成本计入搜索耗时。

均匀分布且局部邻居少时，网格会减少候选检查。密集聚团或半径覆盖整个世界时，仍可能退化为全配对；列表排序还有额外成本，不能保证始终比朴素算法快。界面显示实际测量的搜索耗时和候选次数，不填入推算的性能数据。

运行 `tests/spatial_3d_checks.tscn` 可在无图形模式下验证两种算法与独立的 27 幅周期图像距离参照一致，覆盖空集合、边界/角落、重合、精确半径、单轴少量格子、非整除边长、随机分布、动态增减与统计失效。
