## 1. 优先完成第三人称取景与实际操控验收

目标：保留当前操控语义，解决跟随者靠近相机时遮挡领队的问题，形成可重复的图形验收记录。

当前进展：已完成下列第 1、2 项的可重复画面对比与淡化实现。默认开启「淡化近处个体」，120～240 世界单位内渐变，保留领队与选择高亮；不修改运动、拾取和视距。覆盖 40/200 跟随者、静止/转弯/侧移/后退、300/650 视距，共 16 对开关画面。见 [实现与结果](camera-fade-3d.md)。连续运行中的遮挡持续时间、实际键盘与操控手感仍属于第 3、4 项待验收工作。

实施顺序：

1. 用 40/200 个跟随者，在静止、持续转弯、侧移和后退场景复核默认 300 及约 650 的视距，记录遮挡出现的位置和持续时间。区分相机距离问题与群体过密问题。
2. 建议优先验证仅在透视跟随模式中，对贴近相机的普通个体作平滑淡化。此方案只影响显示，保持领队与选中对象可识别；退出跟随时恢复外观。先比较视觉效果，再确定阈值与开关默认值，避免直接改动群集规则或自动覆盖用户视距。
3. 实际键盘验证 W/S 前后、A/D 左右、俯仰升降、组合输入限速、松键制动，以及静止转动相机不牵动领队。鼠标捕获/释放需用实际键盘确认；现有自动操作工具的物理键码异常不能充当验收失败或成功的依据。
4. 覆盖空格暂停、F1/F2/Esc/F3、文本焦点、失焦、转移领队、重置和世界切换。暂停时只更新目标视角；所有退出途径都清空有效移动输入，不自动重新捕获。界面显式指定或转移领队属于新的操控动作，会自动捕获鼠标；释放状态的右键调视角也需单独实测。

完成条件：默认视距下无持续满屏近景遮挡；领队和选择身份清楚；淡化或其他最终取景方案不改变运动与拾取；相机平滑和鼠标操作有单独图形记录。继续保留相关无图形回归。

本阶段不扩展到相机碰撞、浮动原点或复杂遮挡寻路，也不修改系统 SDK。

## 2. 开放二维与三维的单步控制

状态：已实现并通过完整回归。当前物理频率决定时间步长，暂停后可单步，按钮使用原有更新路径；运行、帮助、待切换或三维捕获期间不执行 UI 单步。详见 [实现与验收](single-step.md)。

目标：暂停时点击现有「单步」，精确推进一个物理时间步，便于观察规则、边界和障碍接触。

已实现语义：

- 按项目当前物理更新频率计算一个固定时间步；运行时禁用单步，点击后仍保持暂停。
- 复用各管理器现有 Step 入口和 ISimulationWorld 的 CanStep / StepOnce，不增加第二套更新路径。
- 单步完成后立即刷新运动状态、调试图形和统计；不重置、重新生成或修改随机种子。
- 继续使用原有焦点与鼠标隔离规则，不新增快捷键。三维点击按钮前需处于鼠标已释放状态，领队沿用当前有效输入语义。
- 相机继续按显示帧更新；单步只推进模拟状态，不能触发连续运行或积累下一帧的额外位移。

完成条件：一次点击只调用一次模拟更新，推进量与直接调用一次固定步一致；运行中无法重复推进；二维/三维、帮助、世界切换和按钮焦点不会触发双重更新。

## 3. 加入个体数量即时增减

目标：提交数量输入后直接调整现有群体，保留其余个体状态，不再要求为了数量变化重置整个场景。

建议语义：

- 仅在 Enter 或失去焦点提交数值后调整，避免输入中间值触发多次大规模增删；运行与暂停状态保持不变。
- 增加时复用 SpawnBoid：观察模式在当前范围内生成；领队模式在当前群体附近生成，不回到原点或激活边界。位置生成需要处理已有障碍，不能静默把新个体批量放进障碍。
- 减少时采用稳定顺序，优先保留领队和选中个体；减到零时清理身份、选择、操控及调试引用，并沿用现有退出领队模式流程。
- 保留现有个体的位置、速度、角运动与 ID，新增个体继续递增 ID；障碍布局和相机操作状态保持原样。
- 种子修改仍只在重置后生效。即时增量生成使用可复现的独立随机序列，不能改变相同种子重置生成的结果。
- 调整结束后使邻居快照及旧统计失效，下一次模拟更新重新测量；二维与三维各自配置保存当前请求数量。

实现前需明确的一个边界情况：若障碍布局无法容纳新增个体，采用有次数上限的尝试并报告实际生成数量；不得无限重试或放宽碰撞约束。最终控件文案应区分请求数量与实际数量。

完成条件：连续增减、减到零、保留/移除领队、选中对象移除、两种搜索、暂停、重置和世界切换都能保持有效状态；在可容纳的布局下数量与请求一致，操作不会搬移原有个体。

## 交付与范围

每一项单独实现、验证并提交。先运行对应场景的检查；完整阶段交付时运行 `tests/run-headless.ps1`。视觉改动另做原生窗口验收，无图形耗时不作为桌面性能结论。

继续采用管理器统一更新、轻量控制器与渲染职责分离。性能优化先测量候选数、模拟耗时和绘制开销；本阶段不引入 GPU、ECS、多线程、对象池或复杂路径规划。
