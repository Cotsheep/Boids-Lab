## 最终行为约定

- 三维观察盒默认 2560×1440×1440，宽、高、深独立保存；改变范围不搬移个体、障碍或重置相机。「显示边界」默认关闭，仅控制边框，软边界仍有效；底面网格单独控制。存在领队时停用边界并隐藏两者。
- 界面指定或转移三维领队后自动捕获鼠标，保留原暂停 / 运行状态。Esc 释放；按钮 / F3 可重新进入。关闭帮助、恢复焦点或恢复界面均不自动重新捕获。
- 鼠标调整相机目标视角，WASD 以该视角为参考；领队朝向跟随实际速度，受角运动限制。静止转动相机不会让领队主动对齐镜头，松键或退出操控后平滑刹停。
- 空格暂停时保留捕获并允许调整视角，但不推进个体运动；释放后右键调视角在暂停时也有效。文本焦点、帮助、失焦和模式切换按现有规则清理输入。
- 领队只做接触阻挡与滑动，不主动绕障；跟随者保留全部群集规则及分离保护，避障优先。无浮动原点或复杂寻路。
- 跟随视距默认 300，范围 80～2000，可保存；Home 恢复默认视距。「淡化近处个体」默认开启，在 120～240 世界单位间渐变，领队和选中个体保持不透明，不修改运动或拾取。
- 单步复用原有模拟更新，按当前物理频率推进一次；运行时禁用，不新增快捷键。三维操作 UI 前须释放鼠标，单步后不触发连续运行。
- 数量只在 Enter / 失焦提交后调整。减少时优先保留领队和选择；新增保留原有个体位置、运动与 ID，并避开障碍。每个新增个体最多尝试 64 次，首次耗尽停止该批，保留请求数量并报告实际数量，可再次提交重试。种子仍在重置后生效。
- 二维既有边界、鼠标领队与障碍规则不变；两种世界独立保存配置，切换时重新生成并暂停。重置保留当前世界的障碍布局，切换世界清除布局。

## 验证与交接

完整 25 组回归和现有图形检查见[自动验证与实机验收状态](3d-implementation-validation.md)。单步专项 137 项断言、数量增减专项 84 项断言已通过；近距离淡化另有 16 组同状态开关画面对比。上述结果不代表真实键盘与连续飞行手感已完成验收。

维护者已明确接手剩余实机验收，项目清单见[实机验收清单](manual-acceptance.md)。本轮约定范围内没有另列的未实现代码任务；后续若验收发现问题，再按实际表现修复并补充回归。尚未填写的人工项目保持待验收状态。

继续保持管理器统一更新、轻量控制器及渲染职责分离，不引入 GPU、ECS、多线程、对象池、浮动原点、相机碰撞或复杂路径规划。编辑器 SDK 检测异常仍是已知环境限制，保留现有命令行构建方式，不修改系统 SDK。
