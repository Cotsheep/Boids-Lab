# 三维障碍物与避障

支持固定在世界坐标中的轴对齐长方体、球体。布局只保留在当前世界实例中，不写入 BoidConfig；Reset 保留障碍物，切换世界或退出清空。避障开关、前瞻时间和间距沿用 BoidConfig，并保存到独立的三维配置文件。

## 操作

- 点击添加形状按钮，再点击世界放置。橙色预览不参与物理计算，Esc、右键或取消按钮取消放置。
- 放置平面穿过相机观察中心并与屏幕平行；放置与拖动坐标不受观察盒限制。领队模式编辑期间冻结相机跟随和编辑平面，结束后平滑恢复。
- 左键选中并高亮，按住拖动。拖动平面穿过该障碍物中心并平行于当前视角；旋转相机后可沿其他方向移动。长方体当前不旋转。
- 面板调整长方体宽/高/深（X/Y/Z）或球体直径；选中对象上 Shift + 滚轮等比缩放，尺寸范围为 16～2000 世界单位。普通滚轮继续调整观察相机。
- Delete 或面板按钮删除。编辑数字时 Delete 不删除障碍物。点击空白取消选择；障碍物与 Boid 互斥选择，按射线距离选择前方对象。
- 暂停和运行均可编辑；暂停不会自动推进个体。编辑造成的重叠在后续单步或恢复运行后的物理步中按接触约束处理。

## 代码职责

| 文件 | 职责 |
| --- | --- |
| Obstacle3D.cs | 长方体/球体尺寸、MeshInstance3D 外观、高亮与线框；不计算 Boid 运动 |
| ObstacleEditor3D.cs | 放置预览、射线拾取、平面拖动、缩放/删除、互斥选择与事件清理 |
| ObstacleAvoidance3D.cs | 有符号表面距离、线段扫描、前瞻转向与接触恢复；不处理 UI |
| BoidManager3D.cs | 每步从共同快照优先计算避障，安全时计算群集力；积分后约束完整路径，再发布真实统计 |
| Boid3D.cs | 运动积分与接触位置/速度修正；自身没有物理帧回调 |
| ObstaclePanel.cs | 共用请求与尺寸信息，三维显示深度；二维保持矩形/圆形控件 |

ISimulationWorld 的 ResizeSelectedObstacle 增加可选 depth 参数，ObstacleSelection 增加 Depth。二维仍使用宽高；共用尺寸范围集中在 ObstacleSize。MainController 根据当前世界维度配置面板，场景切换仍解除所有旧事件绑定。

## 计算过程

1. 每步先保存全体 Boid 的位置和速度快照。
2. 前瞻距离为「速率 × 前瞻时间 + 速率² / (2 × 最大加速度)」，包含近似制动距离。沿实际坐标的完整前瞻线段检查所有障碍物，不分割或传送路径。
3. 根据首次接触面的外法线，保留当前速度的切向分量并加入少量向外分量。正面接近、切向分量为零时，按 ID 确定一个稳定的三维切向方向；深陷时优先向外退出。目标速度差转换为受限加速度。发现危险时使用完整避障转向，避免群集力抵消它；否则正常计算分离、对齐、聚集。
4. 积分后扫描本步实际位移，球体采用线段/球求交，长方体采用三轴区间求交。接触时停在表面外、移除剩余位移和速度中朝内的分量，保留切向分量。三维没有周期边界，观察盒外的障碍也参与检测。
5. 新增、移动、放大障碍物造成的初始重叠沿最近表面法线尝试移出。接触修正直接限制位置/速度，不属于转向加速度积分；朝向随后继续平滑跟随速度。

所有间距从个体中心计算，不根据 Boid 网格外形做刚体碰撞。球体半径加间距，长方体各轴加间距，盒角留距较保守。障碍物固定且不生成周期副本，参与计算不依赖观察盒。领队不接受预测转向，但始终接受接触阻挡与滑动；关闭避障只取消普通个体的预测和接触约束。

最多处理 64 段路径，极端步长超出时放弃剩余位移，不跳过碰撞。重叠恢复最多 8 轮；封闭、互相重叠或填满世界的布局不保证可脱离。此处没有全局路径规划、旋转盒体、刚体反弹或 Boid 之间的硬碰撞。候选障碍逐一检查，未提前引入空间索引。

## 验证

使用 Godot 4.7.2 .NET 无图形模式运行：

```text
dotnet build BoidsLab.sln --no-restore
godot --headless --path . res://tests/obstacle_3d_checks.tscn --quit-after 600
godot --headless --path . res://tests/obstacle_interaction_3d_checks.tscn --quit-after 600
```

几何测试覆盖两种形状、三轴法线/前瞻、速度与加速度限幅、高速薄障碍、滑动、重叠恢复、正反向连续越界、观察盒外前瞻、开关、布局保留与连续避让。交互测试通过真实主场景和视口事件验证按钮、放置、拖动、尺寸、缩放区分、前后遮挡、运行中编辑、帮助/焦点隔离、删除和切换清理。测试配置写在 .godot/validation，不覆盖用户偏好。无图形检查不代替图形验收，也不作为桌面性能数据。
