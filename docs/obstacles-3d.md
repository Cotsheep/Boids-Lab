# 三维障碍物操作

创建菜单支持长方体、球体；场景资源支持凸体及组合凸体。布局只保留在当前世界实例中，不写入 BoidConfig；Reset 保留布局，切换世界或退出清空。避障开关、前瞻时间和间距保存到独立的三维配置。

## 放置与编辑

- 点击添加形状按钮，再点击世界放置。预览不参与碰撞，Esc、右键或取消按钮取消放置。
- 放置平面穿过相机观察中心并与屏幕平行，不受观察盒限制。领队模式编辑期间冻结相机跟随和编辑平面，结束后平滑恢复。
- 左键选中并高亮，按住拖动。拖动平面穿过障碍中心并平行于视角；旋转相机后可沿其他方向移动。菜单长方体暂不提供旋转操作。
- 面板调整长方体宽/高/深（X/Y/Z）或球体直径；Shift + 滚轮等比缩放，尺寸范围 16～2000。普通滚轮继续调整相机。自定义资源支持整体移动、删除，尺寸控件及滚轮缩放禁用。
- Delete 或面板按钮删除；编辑数字时 Delete 不删除障碍。点击空白取消选择，障碍与 Boid 互斥选择，按射线距离选择前方对象；重合障碍优先保留当前选择。
- 暂停和运行时均可编辑。暂停编辑立即同步几何，个体在后续单步或恢复运行时处理重叠。

## 避障行为

普通个体开启避障时先主动绕行，再对完整位移执行接触阻挡与滑动；关闭开关同时关闭这两项。玩家领队只执行接触约束，并始终阻挡。球形查询半径为避障间距，不额外叠加外观尺寸。三维使用实际坐标，盒外障碍同样检测。

接触完成后再提交显示插值，保持相机、拾取与显示姿态一致。封闭、过窄或复杂重叠布局不保证脱困，群体之间没有硬碰撞。
