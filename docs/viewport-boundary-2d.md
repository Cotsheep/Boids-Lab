# 二维视口软边界

在「显示 → 二维观察边界」勾选「使用视口软边界」。默认关闭，旧配置继续使用原有环绕。

| 状态 | 行为 |
| --- | --- |
| 无领队，关闭开关 | 当前相机视口为环绕范围；相机变化和返回观察模式时立即环绕越界个体 |
| 无领队，开启开关 | 当前相机视口为软边界，靠近边缘向内转向，越界后连续返回 |
| 存在领队 | 无限世界；保存开关选择，暂不施加边界 |

`BoundarySteering2D` 与三维采用相同的外侧 20% 缓冲带、平滑增强及 0.5 秒速度响应。只产生转向，不裁剪或传送位置；同轴向外的群集力不能抵消向内回归，最终加速度仍限幅。主动避障优先，边界不能保证高速时绝不出屏。最大加速度为零时不强制回收。

平移、缩放、Home 或窗口尺寸变化立即更新软边界，保留个体和障碍位置、速度、身份与运行状态。暂停不执行转向；下一次运行或单步才逐步回归。关闭软边界时立即恢复原环绕规范化。重置仍按数量和种子在当前视口生成，并暂停、清除身份、保留障碍。

软边界使用实际坐标与欧氏邻居距离，朴素/网格结果一致，调试范围和连线不生成周期副本。障碍检测保留视口外障碍、完整真实位移与接触约束。环绕模式继续使用原对侧邻居、障碍过滤及出口/入口拆段。领队模式的目标感知避障不变。

配置键为二维 `user://boids_lab.cfg` 的 `[simulation] viewport_boundary_2d`，由 `BoidConfig.ViewportBoundaryEnabled` 管理；三维无此控件，两套配置独立。

`viewport_boundary_2d_checks` 覆盖四边及四角连续回归、零加速度、群集与避障优先级、两种搜索及调试、开关/领队/重置切换、暂停及运行状态、相机平移缩放/Home/窗口变化、视口外障碍、真实 UI 保存和世界切换隔离。完整入口及最新结果见[验证记录](3d-implementation-validation.md)，图形手感由维护者验收。
