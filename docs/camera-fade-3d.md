# 三维近距离淡化与验收

日期：2026-10-30。

## 使用行为

三维领队面板新增「淡化近处个体」，默认开启，保存到三维配置的 `visualization/fade_nearby_boids_3d`；旧配置缺少该字段时采用默认值。

仅在有领队的透视跟随模式中，普通个体靠近镜头时逐渐透明：表面距相机不超过 120 世界单位时不可见，120～240 之间渐变，超过 240 恢复不透明。领队、选中领队及普通选中个体仍使用原身份材质，返回观察模式或关闭开关后立即恢复原外观。暂停时也能切换。

显示变化不改变位置、速度、朝向、邻居搜索、障碍接触或点击选择，也不自动调整跟随距离。淡化后的个体仍能按原几何范围被选中，选中后恢复高亮。

## 实现范围

`SimulationView3D` 为当前世界复制并复用一份普通材质，通过 `Boid3D.SetViewMaterial` 应用；原场景资源不变。领队和选择材质具有更高优先级，新增、身份转移、取消与重置均沿用同一外观刷新流程。

使用 Godot 内置 `BaseMaterial3D.DistanceFadeMode.PixelAlpha`，实际项目仍使用 Compatibility 渲染器；没有新增自定义着色器或逐个体透明度更新。属性语义见 [Godot BaseMaterial3D 文档](https://docs.godotengine.org/en/stable/classes/class_basematerial3d.html#class-basematerial3d-property-distance-fade-mode)。

## 自动检查与图形结果

C# 构建零警告、零错误，完整 23 组无图形检查通过。新增 `camera_fade_3d_checks` 的 4694 项断言覆盖默认值、旧配置、开关保存与即时生效、拾取不变、共享材质、身份转移、重置与观察外观恢复。两份相同初始状态的世界连续推进 180 步，淡化开关不同但所有位置、速度、朝向和候选检查数一致。

通过 Godot MCP 在 Intel Arc / OpenGL Compatibility 原生窗口运行 `tests/camera_fade_visual.tscn`，对每个固定模拟快照分别渲染淡化关闭/开启画面。覆盖 40/200 个跟随者，静止、持续转弯、侧移、后退，以及 300/650 两种视距，共 16 对画面；另外检查近镜头遮挡、选中高亮、渐变距离与观察模式恢复。

| 样例 | 关闭时普通个体绿色像素 | 开启时普通个体绿色像素 | 观察结果 |
| --- | ---: | ---: | --- |
| 距相机 20 的遮挡个体 | 316564 | 0 | 遮挡消失，后方领队可见 |
| 200 跟随者静止，视距 300 | 319927 | 103252 | 大面积近景遮挡减轻 |
| 200 跟随者转弯，视距 300 | 254498 | 105344 | 近镜头群体淡化，领队保留紫色 |
| 200 跟随者静止，视距 650 | 15249 | 15249 | 远处群体外观保持一致 |

像素统计仅用于这批固定画面的对比，不代表一般遮挡率或性能指标。绿色按图形检查中的颜色阈值计数，半透明重叠仍可能形成可见面片；选中个体保持不透明，也仍可能遮挡领队。没有加入相机碰撞或自动调整队形。

图形检查脚本会保存 PNG 与 `metrics.csv` 到 `.godot/validation/camera-fade/`，完成后打印 PASS 并退出。该目录不纳入版本控制；脚本与场景可以重复生成结果。运行示例（先按现有流程构建）：

```powershell
& 'D:/app/Godot4.7.2/Godot_v4.7.2-stable_mono_win64_console.exe' --path . res://tests/camera_fade_visual.tscn
```

图形场景通过程序发送控制意图并固定模拟快照，验证实际渲染效果，不代替真实键盘验收或连续飞行的主观评价。现有自动操作工具的物理键码异常仍在；F3/Esc/WASD、捕获释放与平滑追随需用实际键盘确认。
