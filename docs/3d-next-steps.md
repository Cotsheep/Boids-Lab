## 后续开发顺序

### 1. 取消三维环绕，完善观察模式

三维两种模式均不再采用越界传送。普通观察模式使用更大的盒状模拟范围，提供宽、高、深设置并独立保存；模拟范围与相机视野分离，边框和参考网格随范围更新。

建议采用软边界：靠近边缘时向内转向，越界后逐步返回。缩小范围时保留个体当前位置，不批量搬移或重置鸟群。默认尺寸和回归力度由实现阶段调整。

邻居距离、网格索引、调试范围/连线、避障路径须一起去除周期环绕逻辑，统一使用实际三维坐标与直接距离。

### 2. 三维领队与无限世界

复用“选中个体 → 设为领队”的交互，只允许一个领队，并使用区别于普通选择的身份高亮。

有领队即进入无限世界：取消边界约束和边框，邻居搜索与障碍编辑/避障支持无限坐标。其他 Boid 跟随领队身后的区域，持续执行分离与避障，避免全部挤向同一点；领队不被普通群集规则拉走。

取消身份、删除领队或重置时返回观察模式。建议在当前群体附近恢复观察范围，保留现有位置并引导范围外个体回来，避免重新引入传送；重置仍按原有语义重新生成。

### 3. 第三人称相机与领队操控

领队模式改用第三人称透视相机，平滑跟随领队，支持调整跟随距离；普通观察模式保留自由观察操作。

建议先按飞行式控制实现：鼠标控制偏航/俯仰，W/S 前后移动，A/D 侧移；移动以目标视角为基准，可通过俯仰改变飞行高度。领队目标朝向与移动方向解耦，沿用速度、加速度与角运动限制。普通 Boid 继续朝速度方向转向。

进入操控时捕获鼠标，退出操控或打开 UI/帮助时释放；恢复操控需明确操作，避免点击界面时误转向。空格继续固定用于暂停/继续，WASD 在编辑输入框时不控制领队。领队仍受障碍物接触约束。

### 4. 模式衔接与验收

完善领队指定/转移/取消、相机切换、暂停、重置及 2D/3D 切换时的输入和状态清理。更新中文控件与 F2 操作说明，验证两种模式下的搜索、群集、调试及避障。

本轮只调整三维行为，二维已有边界和领队规则保持原样。优先使用 Godot MCP 检查及无图形回归；图形效果需单独验收。现有编辑器 SDK 检测异常尚未修复，不在此计划中改动系统环境。
