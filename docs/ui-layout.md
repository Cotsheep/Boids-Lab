# 参数分类与界面操作

更新日期：2026-10-31。二维与三维共用五类参数面板，所有模拟规则、参数范围和配置路径保持原有语义。

| 页签 | 分组 |
| --- | --- |
| 基础 | 群体生成、平移运动、朝向转动 |
| 群集 | 邻居感知、分离、对齐、聚集；感知半径和分离半径提醒位于同页 |
| 领队 | 唯一身份、跟随队形；三维提供操控按钮与跟随相机设置 |
| 障碍 | 创建和选中编辑、避障开关及前瞻 / 间距 |
| 显示 | 三维观察范围、场景参考、选中个体调试、全体运动方向 |

开始 / 暂停、单步、重置和选择状态常驻左侧顶部，页签下方独立滚动。页签高亮表示当前分类，标题和辅助文字说明参数用途；当前未开放能力不生成空页签。

切换分类会提交正在编辑的数值；数量提交仍去重，Enter 可重试受限生成。旧页焦点在隐藏前释放，键盘 Tab 不进入隐藏控件。每页在当前世界实例中保留滚动位置，F1 隐藏 / 恢复保留当前页，切换二维 / 三维后回到基础页。页内滚轮由 UI 接收，不缩放世界相机。

障碍尺寸与删除按钮只在选中可编辑障碍时显示；放置期间显示取消按钮和放置提示。点击场景选中障碍后，仍通过障碍页编辑，界面不会强制跳页。重置、数量提交、领队捕获与 F1/F2/F3/Esc/空格的既有语义不变。

## 验证

`ui_layout_checks` 包含 257 项无图形断言，覆盖二维 / 三维在 960×640、1360×860、1920×1080 下所有分类及末项可达、无横向滚动、固定操作栏、按页记忆滚动、跨页提交及保存、焦点与帮助隔离、单步、障碍空状态和半径提醒。既有 25 组回归适配分类导航后继续通过；完整入口见[验证状态](3d-implementation-validation.md)。

通过 Godot MCP 启动实际窗口，已查看五类参数页的渲染、点击切换与更新后的帮助弹层，运行错误列表为空。该检查不代替维护者负责的连续飞行手感及完整图形验收。
