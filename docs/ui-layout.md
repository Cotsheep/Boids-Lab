# 参数分类与界面操作

更新日期：2026-11-04。二维与三维共用五类参数面板；二维新增可保存的视口软边界开关，参数范围和配置路径保持独立。

| 页签 | 分组 |
| --- | --- |
| 基础 | 群体生成、平移运动、朝向转动；角速度和角加速度限制共用一个开关 |
| 群集 | 邻居感知、分离、对齐、聚集；感知半径和分离半径提醒位于同页 |
| 领队 | 唯一身份、跟随队形；三维提供操控按钮与跟随相机设置 |
| 障碍 | 创建和选中编辑、避障开关及前瞻 / 间距 |
| 显示 | 二维视口软边界 / 三维观察范围、场景参考、选中个体调试、全体运动方向 |

开始 / 暂停、单步、重置和选择状态常驻左侧顶部，页签下方独立滚动。页签高亮表示当前分类，标题和辅助文字说明参数用途；当前未开放能力不生成空页签。

切换分类会提交正在编辑的数值；数量提交仍去重，Enter 可重试受限生成。旧页焦点在隐藏前释放，键盘 Tab 不进入隐藏控件。每页在当前世界实例中保留滚动位置，F1 隐藏 / 恢复保留当前页，切换二维 / 三维后回到基础页。页内滚轮由 UI 接收，不缩放世界相机。

障碍尺寸只在选中菜单形状且未放置新障碍时显示；删除按钮也支持已选中的自定义障碍。放置期间显示取消按钮和放置提示，隐藏尺寸与删除按钮。点击场景选中障碍后，仍通过障碍页编辑，界面不会强制跳页。重置、数量提交、领队捕获与 F1/F2/F3/Esc/空格的既有语义不变。

「基础 → 朝向转动」的「限制角速度与角加速度」默认开启；关闭时两项上限暂不可编辑并保留原值，外观按速度直接对齐，极低速度保持稳定朝向。切换在暂停时也立即刷新外观，不推进位置；二维、三维独立保存。低速与插值规则见[角运动说明](angular-motion.md)。

## 界面文字与状态提示

已检查主场景、参数标签、悬停提示、统计说明、领队 / 障碍状态，以及两套 F2 操作说明。移除早期「模拟核心尚未实现」占位层和相关运行分支，状态直接显示「已暂停 / 运行中」。

数量输入统一为「目标个体数量」，下方显示实际数量及生成受限后的重试方式；障碍删除按钮为「删除障碍物」。参数提示说明单位、生效时机、与其他设置的关系；显示开关说明作用于选中个体还是全体个体。二维长度统一标为世界像素，与缩放后的屏幕像素区分；三维使用世界单位。统计中的 -- 只表示暂无有效读数，不表示功能未实现。

场景标题显示观察 / 领队模式，WorldHint 根据当前操作即时变化：普通观察提示相机手势；领队跟随提示 F3；操控时提示 WASD、Esc 及暂停状态；选中障碍提示尺寸编辑与删除，放置时提示确认 / 取消；空群体提示增加数量。选中障碍时不会再显示「未选中个体」的引导。选择、领队、暂停和操控是独立状态，不用同一个状态词替代。

F2 按快速开始、界面参数、键鼠、模式边界、数量重置、障碍和群集统计组织，说明数值提交与保存、数量受限、零加速度、二维环绕、三维跟随视角及障碍接触等当前行为。主界面保留操作提示，详细规则集中在说明中。
