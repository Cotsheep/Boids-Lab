# 角运动限制与直接朝向

二维、三维均在「基础 → 朝向转动」提供「限制角速度与角加速度」，默认开启，两种模式分别保存。一个开关同时控制两项角运动上限，不改变线性速度、线性加速度、群集或避障开关。

开启时沿用原有阻尼转向，外观按最大角速度和最大角加速度平滑追随实际运动方向。关闭时外观直接指向当前速度；两项数值暂时不可编辑，原值保留，再开启后继续使用。

直接朝向使用低速滞回：速率不高于 0.01 世界单位/秒时冻结最后稳定朝向，之后需要超过 0.02 才恢复跟随。已经在跟随的个体，在 0.01～0.02 之间继续跟随；已经停稳的个体在该区间继续冻结，避免数值噪声反复触发转向。零速度不归一化、不重置朝向；初始极低速度使用固定初始朝向。二维单位为世界像素，三维为世界单位。

开关切换立即清除角速度和角加速度历史，关闭时更新有效速度的朝向，再开启时从零角运动状态恢复约束。暂停时允许显式切换外观模式，但不推进位置、线性速度或模拟时间；暂停中的普通输入仍不驱动个体转向。

接触滑动可能再次改变速度；关闭限制时，在同一物理步内按接触修正后的最终速度对齐。三维直接模式保留位置插值，旋转使用当前稳定朝向，不再叠加角插值延迟。运行中切换只刷新旋转历史，保留已插值的位置，避免影响跟随相机。三维采用当前朝向到速度方向的最短旋转，支持垂直飞行和恰好掉头，不依赖世界上方向重新计算滚转。

配置键为 `[simulation] angular_motion_limits_enabled`，由 `BoidConfig.AngularMotionLimitsEnabled` 管理。旧文件缺少此键时默认开启，沿用原行为。

`angular_limits_checks` 使用真实个体、管理器、接触查询和 UI，覆盖两种模式、低速滞回、停稳和重启、掉头与垂直方向、开关状态清理、实际碰撞后朝向、真实三维网格尖端、位置插值保持、暂停切换、控件可编辑性、旧配置和世界隔离。完整入口及结果见[验证记录](3d-implementation-validation.md)。
