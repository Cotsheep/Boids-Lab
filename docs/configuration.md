# 参数与配置

本文列出参数默认值、输入范围和保存行为；基本操作见[详细使用说明](usage.md)。文中源码路径均相对项目根目录。

范围与默认值集中定义在 `scripts/simulation/BoidConfig.cs`，UI 从这里获取，不再复制定义。下表为二维 / 三维共用参数；表中的“长度单位”在二维指世界像素、三维指世界单位，不是屏幕像素。

| 参数 | 默认值 | 范围 | 步长 / 单位 |
| --- | --- | --- | --- |
| 目标个体数量 | 200 | 0–5000 | 1，提交后即时增减 |
| 随机种子 | 42 | 0–2147483647 | 1 |
| 感知半径 | 80 | 1–500 | 1 长度单位 |
| 分离半径 | 25 | 1–500 | 1 长度单位，实际范围不超过感知半径 |
| 最大速度 | 120 | 0–1000 | 1 长度单位/秒 |
| 最大加速度（代码中保留 `MaxForce`） | 200 | 0–2000 | 1 长度单位/秒² |
| 最大角速度 | 360 | 0–1440 | 1 度/秒 |
| 最大角加速度 | 720 | 0–7200 | 1 度/秒² |
| 分离权重 | 1.5 | 0–50 | 0.1 |
| 对齐权重 | 1 | 0–50 | 0.1 |
| 聚集权重 | 1 | 0–50 | 0.1 |
| 避障前瞻时间 | 0.75 | 0.1–3 | 0.05 秒 |
| 避障间距 | 12 | 0–100 | 1 长度单位 |
| 领队后方距离 | 80 | 16–500 | 1 长度单位 |
| 领队跟随权重 | 1.5 | 0–5 | 0.1 |

三维另保存以下观察参数：

| 参数 | 默认值 | 范围 / 步长 |
| --- | --- | --- |
| 观察宽 / 高 / 深 | 2560 / 1440 / 1440 | 100–100000 / 10 世界单位 |
| 跟随视距 | 300 | 80–2000 / 1 世界单位 |
| 显示边界 | 关闭 | 仅控制观察盒边框 |
| 淡化近处个体 | 开启 | 仅影响透视跟随显示 |

三条规则、避障及角运动限制默认启用；二维视口软边界默认关闭。参考网格默认显示，邻居关系、感知范围、分离范围与运动方向调试默认关闭。当前范围只是实验用的输入约束，不代表对所有参数组合都有算法效果或性能保证。

「领队 → 跟随队形 → 显示跟随范围」默认关闭，二维、三维分别保存为 `visualization/show_leader_follow_region`；开启后显示领队身后的半透明圆 / 球，不改变运动。未指定领队、跟随权重为零或跟随者少于两名时隐藏，详见[跟随范围显示](leader-follow-region.md)。

键入的数值按 Enter 或失去焦点后提交；除目标数量外，数值控件的上下箭头会立即修改参数，目标数量仍需显式提交。二维配置保存为 `user://boids_lab.cfg`，三维为 `user://boids_lab_3d.cfg`，下次进入对应世界时恢复；不会自动保存运行状态。Windows 默认目录为 `%APPDATA%/Godot/app_userdata/BoidsLab/`。首次启动找不到配置时使用默认值。正常首次加载时，无效类型保留默认值；程序再次向已有配置实例加载时保留该字段的当前值。合法数值按步长取整并限制到范围内。加载或保存失败会显示提示；Reset 不删除配置文件。
