# 个体数量即时增减

日期：2026-10-31。

## 操作

二维和三维的「请求个体数量」均在按 Enter 或离开输入框后提交；输入中间数字、使用上下箭头修改草稿时不会增删。Enter 后的失焦不会重复提交。运行和暂停状态保持不变，新增数量仍受 0～5000 限制。

减少时先从列表末尾删除普通个体，保留较早的个体；领队优先，其次是选中个体。只有一个名额时保留领队；减到零清除选择、身份、操控和调试引用，按原规则返回观察模式。三维在最后领队位置恢复观察盒，二维恢复原环绕规则。

保留个体的位置、速度、朝向、加速度、角运动、实例和 ID，不重置整个群体；新增 ID 在当前一次 Reset 周期内持续递增。障碍布局与相机操作状态保留，移除最后领队时仍执行原有相机模式切换。

## 新增位置与失败反馈

观察模式在当前二维可见范围或三维观察盒中生成。有领队时在当前群体质心附近的方形/立方体区域采样，不回到原点、不启用边界；半边长取感知半径与 `分离半径 × 请求数量^(1/维度)` 的较大值，随群体规模扩大。

新增个体必须处于全部已有障碍及「避障间距」之外，即使关闭主动避障也保留生成检查。每个待新增个体最多尝试 64 个候选位置；若仍未找到位置，停止本次新增，保留成功生成的部分。该次数限制不构成不存在可用空间的证明；界面使用「未找到足够的无障碍位置」表述，显示请求数和实际数。

调整范围或障碍后，再按 Enter 提交相同请求可继续补充；二维观察模式还可通过改变相机可见范围调整生成区域，三维观察范围独立于相机。不会在每帧自动重试；保存的是请求数量，实际数量以界面和统计为准。放置只检查障碍，不新增个体之间的硬碰撞约束。

本改动只约束即时新增的采样；启动与重置保留原有生成语义，不修改旧障碍重叠恢复行为。

## 随机性、刷新与切换

每个世界使用独立增量随机序列，Reset 时由当前种子派生并重新开始；增量不会消耗原有重置序列。修改种子后，增量仍沿用旧序列，直到用户重置。相同初始状态、相同提交顺序及相同障碍布局可以复现增量结果。

增删后邻居结果和旧计时失效，暂停时显示未测量值，下一次单步或运行更新重新计算。三维批量调整结束后统一刷新调试和近镜头材质。UI 通过 `ISimulationWorld.ResizePopulation()` 操作世界；切换前提交并保存旧输入，但跳过即将释放世界的新增工作，目标世界仍按自己的配置重新生成并暂停。

## 验收

C# 构建零警告、零错误，完整 25 组无图形回归通过。`tests/population_checks.tscn` 的 84 项断言使用真实主场景与视口输入检查：

- 输入中不增删，Enter、失焦、原生数值箭头、Enter 后失焦去重、运行中提交，以及独立配置保存。
- 两种搜索下的状态/实例保留、稳定删除顺序、ID 单调增长、统计失效、搜索恢复、重置与增量随机复现。
- 百万级坐标的领队附近新增、选择与身份保留、缩到一只及零只、输入清理和相机模式恢复。
- 矩形/圆形、长方体/球体和避障间距、全部阻塞、部分成功、同值重试、障碍布局保留，以及两种世界增至 5000 个体。
- 世界切换前未提交数量的保存、反复切换后的独立数量与暂停状态。

测试使用独立配置路径；现有回归运行器可以通过 `-Scenes population_checks` 单独执行。当前总结果见[验证状态](3d-implementation-validation.md)，图形与真实键盘操作由维护者按[实机验收清单](manual-acceptance.md)确认。
