# BoidsLab

支持二维与三维的 Boids 群集模拟实验。

## 打开和运行

1. 使用 **Godot 4.7.2 .NET 版**导入本目录的 `project.godot`，构建 C# 项目。
2. 按 F5 启动，通过顶部「二维 / 三维」选择器切换模式。
3. 初始为暂停状态，点击「开始」或按空格运行；暂停时可用「单步」逐步观察。

## 基本操作

| 操作 | 用法 |
| --- | --- |
| 空格 | 开始 / 暂停 |
| 左键轻点 | 选择个体或障碍物 |
| 二维视角 | 在空白处左键拖动平移，滚轮缩放 |
| 三维观察视角 | 右键旋转，中键平移，滚轮缩放 |
| Home | 复位视角；三维领队模式下恢复默认视距 |
| F1 / F2 | 显隐界面 / 查看完整操作说明 |
| 重置 | 重新生成群体并暂停，保留障碍布局 |

左侧面板可调整数量、运动和群集参数。键入数值后按 Enter 或离开输入框提交；数量立即增减，随机种子在重置后生效。

选中个体后，在「领队」页勾选「设为领队」：二维用鼠标引导，三维用鼠标和 WASD 飞行；Esc 释放鼠标，F3 恢复操控。在「障碍」页可添加、调整和删除障碍物。

切换二维 / 三维会重新生成目标世界并暂停，清除当前个体、领队、障碍布局和相机视角；两种模式的参数分别保存。

## 明暗主题

点击顶部「明色 / 暗色」按钮切换主题，选择会自动保存。
