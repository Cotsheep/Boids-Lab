# BoidsLab

> 开发机曾在 Godot 图形操作时蓝屏。2026-10-27 用户更新显卡驱动后，简单测试暂未复现；长期稳定性尚未验证。详细诊断记录保存在本地，不随源码上传。

用于团队技术分享和个人学习的 Boids 实验项目，包含可在运行时切换的 2D / 3D 世界；两者均已实现朴素/网格邻居搜索与三条群集规则。运行环境为 **Godot 4.7.2 .NET + .NET 8 SDK**，语言为 C#。

2D 当前已实现 UI、配置、按数量与种子生成个体、速度/加速度积分、受角速度和角加速度限制的朝向跟随、随领队状态切换的无限/环绕世界、可切换的朴素/均匀网格邻居搜索与实测统计，以及**分离、对齐、聚集三条群集规则**。支持单选高亮、选中个体的感知范围与邻居连线、全体运动方向调试绘制，以及可编辑的矩形、圆形障碍物与避障。

结构参考 [SebLague/Boids 的管理器](https://github.com/SebLague/Boids/blob/fdda4db1368df92fbacd8a644bbe6dc61d705441/Assets/Scripts/BoidManager.cs)与[个体脚本](https://github.com/SebLague/Boids/blob/fdda4db1368df92fbacd8a644bbe6dc61d705441/Assets/Scripts/Boid.cs)：`BoidManager` 统一调度，每只 `Boid2D` 保存自身状态并提供普通更新方法，外观由各自场景中的 `Polygon2D` 显示。当前没有引入 GPU 计算。

二维支持鼠标目标领队；三维支持第三人称飞行领队。两者都使用唯一身份与身后跟随区域。

当前约定范围内的开发已完成，后续实机验收由维护者进行。文档入口见[文档导航](docs/README.md)，交付范围见[开发计划完成记录](docs/next-development-plan.md)。

项目采用普通全窗口游戏的结构：`Game (Node)` 下分别放置 `World (Node)` 与 `UI (CanvasLayer)`。Node2D / Node3D 世界直接显示在根视口中，Control 面板作为 HUD 覆盖在世界画面上。`main_3d.tscn` 继承主场景，只改变默认进入的世界。两个入口均可通过顶部选择器在运行时切换 2D / 3D；默认 F5 仍进入 2D。

## 打开和运行

1. 使用 Godot **4.7.2 .NET 版**导入本目录的 `project.godot`。已有项目目录仍为 `boids`，应用和程序集名称为 `BoidsLab`。
2. 在编辑器中构建 C# 项目。2D：打开 `scenes/main.tscn` 后按 F6，或直接按 F5。3D：打开 `scenes/main_3d.tscn` 后按 F6。
3. 也可以先在本目录运行 `dotnet build BoidsLab.csproj`，再由编辑器启动。本机现有编辑器 SDK 检测异常尚未修复，已验证的命令行方式见[本机构建说明](#本机构建说明)。

初始窗口为 1360 × 860，最小为 960 × 640。这里的“全窗口”指游戏世界使用整个根视口，不切换操作系统的独占全屏模式，也没有修改原生窗口模式。HUD 顶部显示标题和状态，左侧参数按页签分类，页内可滚动，底部统计项可换行。空白 UI 和提示文字不拦截鼠标，有交互的面板与控件正常接收输入；参数面板内滚动不会同时缩放相机。使用 Compatibility 渲染器，无第三方插件或素材依赖；原有 Godot 图标保留。

## 参数面板

开始 / 暂停、单步和重置固定在左侧顶部，下方显示选择或领队状态。参数分为五页：

| 分类 | 内容 |
| --- | --- |
| 基础 | 数量、种子、速度 / 加速度与朝向转动上限 |
| 群集 | 搜索方式、感知半径、分离 / 对齐 / 聚集开关及权重 |
| 领队 | 身份、跟随距离与权重；三维另有操控、视距与近处淡化 |
| 障碍 | 创建、选中后的尺寸编辑、删除和避障参数 |
| 显示 | 参考网格、选中个体范围和邻居连线、全体运动方向；三维另有观察范围与边框 |

场景标题显示观察 / 领队模式，下方提示随选择、操控、障碍放置及空群体状态切换；状态栏区分目标数量与实际数量。F2 说明按当前二维 / 三维操作分别整理。

各页记住本次世界中的滚动位置；切换分类会提交正在编辑的数值，隐藏界面后恢复原页，切换世界后回到基础页。障碍尺寸仅在选中可编辑障碍时出现。详见[界面分组说明](docs/ui-layout.md)。

## 冰岩明暗主题

顶部「明色 / 暗色」按钮切换主题，按钮文字表示当前模式。明色采用清透暖白底、杏橙障碍和鲜橙强调色；暗色采用炭灰底、焰橙强调色。普通 Boid 使用鲜橙 / 杏橙色，三维主体不受光照压暗；选中金色、领队紫色仍各有区分，三维选中领队显示粉色。

主题同时覆盖界面、帮助、二维 / 三维世界、障碍与调试线条。选择保存在独立的 `user://boids_lab_ui.cfg`，重启及切换世界后沿用；不重置群体、相机或暂停状态。首次启动默认暗色。配色集中在 `themes/bingyan_light.tres` 与 `themes/bingyan_dark.tres`，可在 Godot Inspector 分组调色，Remote Inspector 中的颜色修改即时刷新。配色与实现见[主题说明](docs/themes.md)。

## 运行时世界切换

顶部「二维（2D）/ 三维（3D）」选择器可直接切换。目标世界按自身的数量和种子重新生成，并保持暂停；两种模式分别保存参数与显示开关。切换会清除个体运动状态、选择、领队、障碍物布局和相机视角，HUD 显隐状态保留，旧帮助弹窗关闭。

世界场景、配置文件路径和对应操作说明分别集中在 `scenes/worlds/world_2d.tres`、`world_3d.tres`。详见 [世界切换说明](docs/world-switching.md)。

## 3D 观察与领队飞行

运行 `scenes/main_3d.tscn` 或从顶部切换到三维。初始暂停，空格开始 / 暂停，F1 切换界面，F2 查看完整中文说明。数量在提交后即时增减，种子在重置后生效；暂停时可点击「单步」推进一个固定物理时间步，之后仍保持暂停。操控领队时先按 Esc 释放鼠标再操作界面。

- 普通观察使用可编辑的软边界盒，默认 2560×1440×1440。宽、高、深范围 100～100000，步长 10；修改范围保留个体位置和当前视角。靠近边缘逐渐转向，越界后回归，三维不再传送。
- 正交观察相机支持右键旋转、中键平移、滚轮锚点缩放；Home 根据最新范围重新取景。模拟范围与相机视野独立。
- 「显示 → 场景参考 → 显示边界」默认关闭，勾选后显示观察盒边框并保存选择；只控制显示，软边界仍生效。底面网格由「显示网格」单独控制，领队模式下两者均隐藏。
- 选中个体后勾选「设为领队」，进入无限世界与第三人称透视相机，并自动捕获鼠标操控领队；保持原有暂停 / 运行状态。领队紫色、选中的领队粉色、普通选中金色。界面转移唯一身份时清空旧输入并操控新领队；取消普通选择不清除身份。
- 鼠标调整相机视角，W/S 前后、A/D 左右均以该视角为基准；领队朝向跟随实际速度方向，松键或释放控制后平滑刹停。空格暂停保留捕获和视角调整，Esc 释放。释放后可右键拖动调整跟随视角，暂停时也有效；通过「操控领队」按钮 / F3 恢复捕获。F1/F2、失焦、移除领队、重置和世界切换均释放并清空输入，不自动重新捕获。
- 跟随视距默认 300、范围 80～2000，可通过滚轮或控件保存，Home 恢复默认。观察角度与缩放在回到普通模式后保留，并移到当前群体附近。
- 「淡化近处个体」默认开启并保存，在跟随视角中让贴近镜头的普通个体逐渐透明，减轻遮挡；领队和选中个体保留高亮。开关不改变运动、拾取或观察模式的外观。详见 [相机淡化与验收](docs/camera-fade-3d.md)。
- 跟随者追随实际领队朝向后方的球形区域，按人数立方根扩大，保留全部群集规则及分离保护；群集速度在领队参考系中计算，避免持续抵消共同前进速度。
- 朴素 / 均匀网格统一使用真实坐标和直接距离，网格检查相邻 27 格；调试球和连线不再周期复制或裁剪到观察盒。详见 [三维搜索](docs/neighbor-search-3d.md)。
- 长方体 / 球体可在任意坐标放置、拖动和缩放；跟随视角下编辑期间固定相机和编辑平面。普通个体提前避障，领队只执行接触阻挡和滑动，即使关闭避障也保留领队接触。详见 [三维障碍](docs/obstacles-3d.md)。
- 取消或删除领队后，以剩余群体质心（空群体取原领队位置）恢复观察盒，不传送。重置按当前盒和种子重新生成并暂停，保留障碍布局；切换世界清除运行状态。

三维配置独立保存在 `user://boids_lab_3d.cfg`，包括范围尺寸和跟随视距。世界单位不隐式换算成米。默认速度为 120 世界单位/秒，所有线性和角运动受共享上限限制；无限世界仍使用 Godot 单精度坐标，没有浮动原点、相机碰撞或复杂寻路。

| --- | --- |

| 鼠标左键轻点 | 单选并高亮个体或障碍物；再次点击选中个体或点击空白取消选择，暂停和运行时均可操作 |
| 设为领队 | 将选中的 Boid 指定为唯一领队；选中其他个体再勾选可转移身份，取消选择不会取消身份 |
| 移动鼠标 | 领队持续跟随场景中的鼠标光标，无需点击；UI、帮助弹窗和障碍物编辑期间保留原目标 |
| 鼠标右键 | 取消障碍物放置 |
| 鼠标左键拖动 | 拖动障碍物本体移动障碍物，拖动其手柄调整大小；在空白世界画面上拖动则平移视角，可向任意方向继续拖动 |
| 鼠标滚轮 | 以鼠标位置为中心缩放；范围为初始参考倍率的 0.25–8 倍；无领队时同步环绕边界，有领队时仅改变视角 |
| Home | 恢复初始参考视角并居中；编辑输入框时优先处理文本操作 |
| 开始 / 暂停 | 开始或暂停统一物理更新；根据邻居计算转向，再积分速度与位置 |
| 重置 | 暂停，按当前数量、种子和最大速度重新生成个体；清空加速度、角速度与计时，保留已创建的障碍物 |
| 目标个体数量 | 按 Enter 或离开输入框后即时增减，保留现有个体状态；缩减时优先保留领队和选中个体，新增避开障碍；下方显示实际数量及生成受限提醒 |
| 添加矩形 / 添加圆形 | 进入放置模式，点击世界画面创建并选中；Esc、右键或取消按钮结束放置 |
| 障碍物尺寸 / 缩放手柄 | 修改选中矩形的宽高或圆形的直径；鼠标位于选中障碍物上时，Shift + 滚轮等比缩放 |
| Delete / 删除障碍物 | 删除选中障碍物；编辑输入框时 Delete 保留文字编辑行为 |
| 单步 | 暂停时推进一个固定物理时间步并刷新调试与统计，之后仍保持暂停；运行时禁用 |
| 参数与规则开关 | 修改同一个 `BoidConfig` 实例并保存配置；三条规则的开关、权重与半径在下一次运行更新生效 |
| 邻居搜索 / 搜索方式 | 切换朴素遍历与均匀网格；默认朴素遍历，选择会保存，不重建群体 |
| 显示网格 | 显示或隐藏间距 40 世界像素的辅助网格，与邻居搜索无关 |
| 显示邻居关系 | 仅绘制选中个体与当前邻居的连线，没有选中对象时不画线 |
| 显示感知范围 | 仅显示选中个体的感知范围，没有选择时不显示；切换选择时跟随新对象 |
| 显示分离半径 | 独立显示选中个体的实际分离范围，半径取分离半径与感知半径的较小值；默认关闭并保存开关状态 |
| 显示运动方向 | 对全体个体生效，不依赖选择；静止个体不显示方向箭头 |
| 性能统计 | 显示真实个体数量、引擎 FPS、本步更新/搜索耗时、候选检查次数和平均邻居数；尚未测量时显示 `--` |

键鼠指引、参数说明和调试颜色图例集中在操作说明中，主界面保留实际控件、状态、统计及悬停提示。说明采用窗口内弹层，内容可滚动；打开或关闭都不自动改变模拟运行状态。弹层打开时，背景的选择、视角和参数操作被拦截，空格仍能暂停/继续；打开前尚未结束的拖动或点击会取消。说明默认隐藏，不保存其打开状态。

启动时按配置生成个体，初始为暂停状态。「目标个体数量」在 Enter 或离开输入框后即时增减，运行状态保持不变；种子修改仍在**重置**时生效。新增个体使用独立随机序列，在观察范围或领队群体附近避开障碍生成；尝试次数有限，未达请求数量时显示实际数量，调整布局后可再次提交。详见 [数量即时增减](docs/population-resizing.md)。相同种子、数量、当前观察范围与最大速度仍能在当前引擎版本中复现重置后的初始状态。运动上限修改后在下一次模拟更新时生效；有转向目标时最大速度也用作目标速率，没有邻居时不会仅因为提高速度上限就自动加速。

`Boid2D.SetAcceleration(Vector2)` 保留为持续的外部加速度输入，传入 `Vector2.Zero` 撤销。每步群集转向单独传入 `UpdateBoid(delta, steeringAcceleration)`，与外部输入相加后限制总加速度；规则不会覆盖外部输入，也不会把上一帧转向残留到下一帧。角加速度只控制外观朝向平滑跟随实际速度方向，不直接旋转速度向量。具体公式与调用示例见 [架构说明](docs/architecture.md)。

## 2D 领队与全局跟随

选中 Boid 后勾选“设为领队”，该个体以紫色本体和菱形持续标记；普通选择仍使用金色圆环。选中领队后取消勾选可解除身份，无选中个体时复选框禁用。领队与普通选择分开保存，点击其他个体、障碍物或空白不会改变身份。

领队持续跟随世界画面中的鼠标光标，紫色十字圆标记表示当前目标。鼠标停下时，领队接近目标后减速停止。暂停时仍更新目标标记，继续运行后才移动；隐藏 HUD 后仍可操作。光标悬停 UI、打开帮助、编辑障碍物、离开窗口或窗口失焦时保留最后目标；模拟本身不自动暂停。

其余 Boid 追随领队身后的区域，不受发现领队的感知半径限制。区域半径随跟随数量和分离半径增加，进入区域后匹配领队速度，不再全部挤向同一点；局部分离仍由感知范围内的邻居决定。近邻过近时，减少跟随、对齐和聚集合力中抵消分离的分量，保留切向运动。默认“领队后方距离”80 世界像素表示领队到区域前缘的间隔，跟随权重默认为 1.5；关闭分离规则仍允许个体靠近。它不是固定编队或硬碰撞系统。

目标与跟随区域都使用世界坐标，不绕回屏幕另一侧。相机移动后按当前光标重新换算目标，个体不会随相机传送。领队不参与三条群集规则，避障优先；当前没有全局路径规划，障碍物内部或封闭区域的目标可能不可达。重置、移除领队或解除身份会清空目标；身份和目标不跨运行保存，跟随参数会保存。

## 2D 障碍物编辑与避障

在“障碍物”面板选择添加矩形或圆形，再点击世界画面放置。放置后自动选中并显示高亮边框和缩放手柄。拖动本体移动；矩形右下角手柄分别调整宽高，圆形右侧手柄调整直径。面板提供对应尺寸输入，也可将鼠标放在选中障碍物上，用 Shift + 滚轮等比缩放。正常滚轮仍用于相机缩放。尺寸范围统一为 16–2000 世界像素。

暂停和运行时均可创建、选择、编辑和删除障碍物。障碍物与 Boid 的选择互斥；操作 UI 不会拖动世界或误删障碍物，编辑输入框时 Delete 只编辑文字。F2 弹窗会结束未完成的放置或拖动，并拦截背景输入。重置只重新生成鸟群，保留障碍物；障碍物布局当前仅属于本次运行，不保存到配置文件。

避障独立于分离、对齐、聚集三条群集规则。开启时沿当前速度提前检查障碍物，必要时优先避让。“前瞻时间”默认为 0.75 秒，“避障间距”默认为 12 世界像素；间距以个体中心到障碍物表面的距离计算。障碍物固定在世界坐标中，不随相机移动，也不会因相机缩放而改变实际尺寸。有领队时检测所有障碍物；无领队时只检测与当前区域相交的障碍物，传送前后的轨迹分段扫描。

运动时还会扫描本步路径，接触障碍物时截断位移并保留沿表面的速度，避免高速直接跨过薄障碍。新增或放大障碍物造成的重叠也会尝试移出。关闭避障会同时关闭转向和接触约束。矩形角部采用保守留距；障碍物相互重叠或封满整个视野时，不保证存在可退出的自由位置。这不是刚体物理系统。

## 三条群集规则

- **分离**：避开分离半径内的近邻，越近的邻居对分离方向影响越大。新增分离半径默认 25，实际范围取它与感知半径的较小值。二维与三维面板在分离半径大于感知半径时，于分离半径下方显示黄色提醒；调整任一半径后立即更新，相等或恢复合理范围时隐藏，保留输入数值。
- **对齐**：朝感知范围内邻居的平均速度方向转向，目标速率为最大速度。
- **聚集**：朝邻居中心靠拢；中心方向由世界坐标相对位移的平均值计算。

三条规则各自转换为受限加速度，乘以权重后求和，再限制总模长。关闭某条规则或将其权重设为 0，可消除它在下一步的贡献；无群集转向、避障或外部加速度时保持惯性运动。没有最小速度限制。完全重合的个体会根据 ID 确定相反分离方向，避免除零。此实现是转向行为，不是保证个体之间互不穿透的碰撞系统。

## 2D 世界边界

二维地图模式由是否存在领队自动决定，无需额外开关：

- **有领队**：无限世界，个体出屏后继续运动；相机拖动、缩放和 Home 只改变观察位置。
- **无领队**：以相机当前可见矩形为环绕边界，个体越过一侧会从对侧进入，并保留越界余量、速度和朝向。拖动、缩放、Home 或视口尺寸变化后，即使暂停也立即把越界个体传送回新范围。

指定领队立即进入无限模式；取消身份、删除领队或 Reset 恢复环绕模式，已有的远处个体立即按当前视口环绕回来。更换领队不会经过中间环绕状态。普通取消选择、隐藏 HUD、暂停或将跟随权重设为零，都不影响领队身份及地图模式。`ViewBounds` 始终保存可见矩形，`WrapBounds` 在无领队时返回它，有领队时为 null。

`BoidManager.WorldSize` 的 1280 × 720 只作为初始与 Home 的参考尺寸。相机适配窗口比例，缩放仍限制为参考倍率的 0.25–8 倍；平移不设地图范围限制。背景和网格始终覆盖当前视口，网格固定在世界坐标上。这里的“像素”指世界像素，缩放后不一定等于屏幕像素。坐标仍受 Godot 单精度浮点数精度限制，没有额外实现浮动原点。

## 2D 选择与调试观察

左键按下时记录命中的个体，松开且移动不足 5 个视口像素时确认选择，因此运行中的个体即使已经移开，也能被选中。超过阈值则平移相机，不改变选择；从 UI 控件开始的操作只影响 UI。命中测试使用实际三角形，同时保留 10 个视口像素的点击容差，缩小时仍可点击。普通个体选中时显示金色外观和圆环，取消后恢复原始颜色；领队始终保留紫色本体，被选中时叠加金色圆环。重置或移除该个体会清除选择。

青绿色圆弧表示选中个体的感知范围，加粗为 3 个视口像素；橙色圆弧表示其实际分离范围，线宽为 2 个视口像素。两种范围可独立开关，缩放时保持屏幕线宽。蓝色箭头表示全体个体的实际速度方向，金色连线只表示选中个体的邻居。没有选中对象时，不生成范围和连线；范围圆的生成成本不随群体数量增长。箭头长度随速率变化并限制在 8–80 个视口像素，便于观察方向，不作为精确速度标尺。有领队时，圆弧和连线按世界坐标裁剪显示；无领队时，跨边界部分衔接到对侧，范围覆盖整个环绕区域时以视口边框表示。

连线依据**当前画面上的位置**查询，不依赖上一物理步的缓存，因此暂停、首次开始前、改变半径或调整相机后都能立即查看。它只对选中个体做一次 O(N) 距离扫描，不修改模拟搜索结果或性能统计。调试绘制开销会影响 FPS，但不计入模拟更新/搜索耗时。各显示开关会保存，选择状态不保存；隐藏 HUD 后仍可选择并查看已开启的调试显示。

## 2D 邻居搜索与性能对比

每次物理更新先复制所有个体的位置与速度，再搜索邻居、计算所有个体的转向，最后统一移动。有领队时按直接世界距离、无领队时按最短环绕距离判断邻居：包含恰好位于感知半径上的个体与重合位置的其他个体，不包含自身。两种方式输出相同的邻居集合，遍历顺序可以不同；转向会有浮点累加顺序造成的微小差异，不承诺长期轨迹逐位一致。

- **朴素遍历**：每个个体检查所有其他个体，每步距离检查次数为 `N × (N − 1)`。
- **均匀网格**：每步重建空间格子，只检查自身与相邻格中的候选，再进行同样的距离判定。无限模式的格子边长等于感知半径，按世界坐标定位；环绕模式则均分当前边界，各轴超过一格时格子边长不小于感知半径，索引跨边界取模。一列或两列时去重访问，两种模式都只保存占用的格子。屏幕上间距 40 像素的辅助网格与它独立。

候选检查次数按有向查询计算，甲检查乙和乙检查甲分别计数，不包含自身或格子查找。平均邻居数是所有个体的邻居数之和除以实际数量，空群体测量后为 0。搜索耗时包含快照、网格构建、距离检查和结果写入；模拟更新耗时还包含群集转向、避障、运动积分、接触约束，不含渲染。界面每 0.25 秒显示最近一次物理步的读数，并非累计或窗口平均。

暂停会保留最后一次测量。重置、增删个体、修改搜索方式/半径、切换地图模式或无领队时改变相机边界后，旧结果失效，统计恢复 `--`，下一次运行更新重新测量。

对比时可先将最大速度设为 0，固定数量、种子、半径与相机位置后重置，开始运行并切换搜索方式。这样两种算法处理的是相同的静止分布；跳过首次测量，多观察几次耗时和候选次数。移动场景应保持相同初始条件与运行步数。FPS 同时受节点绘制与界面开销影响，不能单独代表搜索效率。网格在分布较均匀、局部邻居较少时减少候选；个体密集或半径覆盖整个区域时仍可能退化到二次复杂度，没有保证的固定加速倍数。

## 本机构建说明

本机的 `dotnet --info` 遇到了 workload 安装器异常。首次还原使用以下方式，仅在当前进程中关闭 workload 解析，没有修改系统设置：

```powershell
$env:MSBuildEnableWorkloadResolver = 'false'
$env:DOTNET_CLI_WORKLOAD_UPDATE_NOTIFY_DISABLE = 'true'
dotnet build BoidsLab.csproj --source D:/app/Godot4.7.2/GodotSharp/Tools/nupkgs
```

`--source` 指向本机 Godot 自带的官方包；其他机器应改成自己的安装路径，或使用常规包还原。项目本身没有写入机器专用绝对路径。

还原完成后，可以使用常规 `dotnet build BoidsLab.sln --no-restore --verbosity minimal` 构建。最新功能提交已通过该命令，零警告、零错误。编辑器仍曾报告需要 SDK `10.0.11` 而无法加载 `Microsoft.Build`；本轮没有改动系统 SDK，也不将命令行成功视为编辑器构建已修复。
